# Задачи ко второй лекции

У каждой задачи два файла: `NN-имя.js` — условие и пустая функция, `NN-имя.test.js` — автотесты рядом.
Всего задач: 127, из них ★ минимум — 61.
Теория, разборы и готовые решения — в `js-lekciya-2.html`. Там же 7 устных вопросов, которых здесь нет.

## Как запускать

Нужен Node.js 18 или новее (проверить: `node -v`). Открой эту папку в VS Code, дальше в терминале:

```
node test.js                            все задачи и итог по блокам
node test.js --must                     только минимум ★
node test.js 04                         только блок 4
node test.js myReduce                   одна задача — подробно, по каждому тесту
node 04-join-reduce/05-myReduce.js      запустить свой файл и посмотреть примеры
```

## Что делать

1. Открой файл задачи: сверху условие и правила, ниже — пустая функция и примеры вызовов.
2. Напиши код внутри функции. Не переименовывай её и не меняй список параметров — по ним ищут тесты.
3. Запусти проверку. Пока функция пустая, задача считается «ещё не начата».

## Что именно проверяется

- **Ответы** на 3–12 случаях: обычные, пустые строки и массивы, дырки, отрицательные индексы, ожидаемые ошибки.
- **Правила задачи**: сколько можно циклов, разрешена ли рекурсия, какие методы нельзя.
  `forEach`, `map`, `filter`, `slice`, `includes`, spread `...arr` — это тоже циклы, они считаются.
- В задачах формата экзамена — что нет `parseInt`, `Number()`, готовых методов и массивов.

Бесконечный цикл ничего не сломает: каждый тест прерывается через 2 секунды и пишет, что задача зависла.

## Задачи «что выведет код»

В файле `NN-chto-vyvedet.js` нет функции — есть код и пустой шаблон:

```js
const answer = `

`;
```

Впиши туда ответ — каждая строка вывода отдельной строкой — и запусти проверку. Пробелы и кавычки не важны.
Сначала ответь, потом запускай сам файл: он выведет правильный ответ и подсказывать станет нечему.
